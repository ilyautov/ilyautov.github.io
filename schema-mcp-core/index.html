schema-mcp-core: ядро, на котором собраны серверы к российским API

Сам по себе не подключает ничего. Сервер поверх него приносит каталог методов в endpoints.yaml и тонкий server.py, всё остальное берёт отсюда. Лицензия MIT.

Зачем отдельный пакет

Ядро это 2 200 строк, а сервер поверх него 66. Пять серверов живут отдельными репозиториями, и без общего ядра каждый нёс бы свою копию одного кода. Правка в безопасности тогда чинила бы один репозиторий и оставляла четыре сломанными.

Что внутри

  • registry: каталог методов из YAML, поиск обычными словами, пагинация.
  • safety: класс доступа read, write или destructive у каждого метода.
  • client: асинхронный HTTP, авторизация, повтор на 429, белый список доменов.
  • credentials: ключи на несколько кабинетов, файл вне репозитория с правами 600.
  • tools: готовый набор инструментов MCP: поиск, описание, вызов, кабинеты.
  • doctor: отчёт «взлетит ли эта установка», список сервисов задаёт вызывающий.
  • paginate: выкачать все страницы одним вызовом, только для чтения.

Чего ядро не делает

Не ходит в сеть само, не хранит ключи в репозитории и не пишет в сервис без подтверждения: методы классов write и destructive требуют явного согласия на стороне вызова.

Кто на нём стоит

Серверы к hh.ru, VK, Диадоку, СБИС и Честному знаку. Все пять собраны одним набором в business-mcp-ru.

pip install schema-mcp-core
