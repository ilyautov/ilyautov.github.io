ilyautov

MCP-серверы к российским сервисам, скиллы для Claude и инструменты вокруг ИИ-агентов. Открытый код, лицензия MIT.

Маркетплейсы

marketplaces-mcp-ru главный
Кабинеты Wildberries, Ozon, Яндекс Маркета и Авито в ИИ-ассистенте. 1022 метода, запись за гейтом безопасности.
ozon-mcp-ru
Только Ozon Seller API: товары, заказы, цены, остатки, финансы, отзывы. 441 метод.
wildberries-mcp-ru
Только Wildberries: продажи, остатки, карточки, цены, отчёты. 307 методов.
yandex-market-mcp-ru
Только Яндекс Маркет: заказы, товары, цены, отчёты, отзывы. 165 методов.
avito-mcp-ru
Только Авито: объявления, чаты, заказы, автозагрузка, отзывы. 64 метода.
lamoda-mcp-ru
Кабинет продавца Lamoda: товары, цены, остатки, заказы, отгрузки, акции, возвраты. 155 методов.

Деловые сервисы

business-mcp-ru
Пять серверов одним набором: hh.ru, VK, Диадок, СБИС, Честный знак. 698 методов.
moysklad-mcp-ru
МойСклад по JSON API 1.2: остатки, товары, заказы, документы, отчёты. Мультикабинет, поиск по-русски.
realtycalendar-mcp
RealtyCalendar для посуточной аренды: брони, шахматка, объекты, вебхуки. Работает и от локального зеркала.
schema-mcp-core
Ядро, на котором собраны серверы: каталог эндпоинтов, классы доступа, HTTP-клиент, хранилище ключей.

Скиллы для Claude

humanizer-ru
Убирает следы нейросети в русском тексте и возвращает живой голос. Детерминированный сканер, 64 паттерна.
small-business-ru
34 скилла для малого бизнеса: налоги УСН, сроки уплаты, проверка контрагента, деньги и найм.
humanizer-it
То же для итальянского: кальки с английского, номинальный бюрократит, пропавшие частицы. 52 паттерна.
consilium-principis
Совет наставников из общественного достояния. Каждую цитату сверяет дословно с источником или молчит.

Инструменты

cordon
Слой между недоверенным текстом и действиями агента: снимает скрытый слой, помнит источник данных, держит вызовы в границах задачи.
doc2md
Пакетно превращает Word, Excel, PowerPoint, PDF, EPUB, RTF и CSV в чистый Markdown до того, как их прочитает агент.
rusvoice
Русская озвучка своим голосом: ударения, бренды, твёрдая «э», аббревиатуры, транслит. Слышно, что получится, до синтеза.
hefest
Рабочее место по химической безопасности завода: паспорта ГОСТ 30333, аварийные карточки, зоны АХОВ, СИЗ. Офлайн, без выдуманной нормативки.
